The masthead readout

JARVIS runs on your Claude subscription, so the number that matters is how much of the five-hour and seven-day windows is gone — not a dollar figure for API calls nobody made. The gauges are the hero; what is running now and what ran today sit beside them.

The reading only exists once the brain has taken a turn, so the cluster always says where its numbers came from and when. It never draws a number it does not have: an unmeasured window is hatched and says so, because an empty gauge and a 0% gauge are the same picture and one of them is a lie.

Sessions

The one question this view exists to answer is “does this want me, and why?” — so that is what the panel opens with, and everything else on it is context for that one sentence. A blocked session gets the flooded band and the CLI’s own reason, verbatim, in the largest type on the panel. Every other state gets the same band, quiet, saying in words that nothing is asked of you. If every state shouted, none of them would.

Clicking never moves the list. Both columns are always in the grid — the shared .split primitive that Projects and Specs use — so selecting a session swaps the right-hand column and nothing under the cursor shifts. Below 900px that column becomes a right-hand sheet over a scrim; Escape, Close, the scrim and clicking the open row again all put it away.

Every fragment below is the markup sessions.ts actually emits, lifted out of a running page rather than hand-copied, so this page cannot quietly drift from what ships.

The unit is not dollars — JARVIS runs on the subscription and bills nobody, so a cost figure is a price list for calls that never happened.
